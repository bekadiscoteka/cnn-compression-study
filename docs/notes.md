ST validation on the board matches the ONNX model (cosine 1.0, RMSE 2e-6).

Two pipeline defects suspected, not a finding: (1) MinMax calibration lets a few outlier activations set the whole int8 range, which narrow pruned layers cannot afford; (2) QAT trained with moving-average ranges, but the exported model was recalibrated with MinMax, so the ranges QAT adapted to were thrown away.

Rule fixed before running; ties within 0.1 pp go to the simpler method. QAT now trains with activation ranges computed by the same rule on the same 500 calibration images, refreshed every epoch. Results of the re-run go to results_v2.csv; v1 is kept.
